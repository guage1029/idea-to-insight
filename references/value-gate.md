# 读者价值关口

不是所有值得想的东西都值得写成文章。判断的是：特定读者读完后，是否能形成更准确的新判断、解释框架或行动选择；认知增量本身可以构成价值，不要求每篇都有行动方案。

## 检查维度

- **读者**：谁会因此改变判断？“所有人”不是有效读者定义。
- **读前状态**：他们现在可能误解、忽略或无法判断什么？
- **读后增量**：文章能让他们多看见哪一条关系、因果、取舍或边界？
- **独特贡献**：用户的观察、经验、问题或筛选判断在哪里？若只给一个方向，模型即可写出通用答案，说明问题可能设错或个人增量尚未出现。
- **支撑强度**：核心判断有何事实、例子、经验或推理支撑？证据边界是什么？
- **反方韧性**：最强反例能否被处理，而不是被删掉？
- **表达可得性**：最核心的洞见能否用清楚的话说出，而无需靠长篇铺垫？

## 结论

选择其一，并给出依据与未决点：

- **值得写**：读者变化明确，独特贡献和论证主干足以支撑文章。
- **继续探索**：可能有价值，但一个会改变判断的关键缺口仍未解决；再问一个最关键问题。
- **暂不建议写**：目前没有具体读者收益、独特判断或足够支撑。明确说明原因，并由用户选择暂存或放弃。

不做维度求平均的伪精确评分。即使用户决定继续写，也保留价值风险；不为了通过关口而制造强结论。
