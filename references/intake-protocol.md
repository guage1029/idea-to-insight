# 大量输入：收集与整理

## 输入期间

用户可能一次或多次发送大量碎片。每批只回复简短确认，例如“收到，继续发；说‘开始梳理’后我再整理。”不要先总结、分类、追问、评判、搜索或起草。除非用户明示，否则不要把“暂时停顿”误判为输入完成。

用户说“开始梳理”或明确表示发完后，再开始整理。

## 输入完成后的素材地图

用短而可审阅的结构呈现：

1. **写作方向**：用户明确想写什么；若未说清，标“待澄清”。
2. **核心素材**：按主题归类，标明重复、互相补充的内容。
3. **可能主线**：最多 2–3 条，并标为候选，不冒充用户已决定。
4. **关系与冲突**：因果链、优先级、矛盾观点和隐含前提。
5. **事实 / 体验 / 判断 / 推测 / 未知**：分开，不将推测写成事实。
6. **缺口与旁支**：指出缺少哪些证据、哪些内容暂不支持主线。

如有可能的主线，说明它与用户声明的方向是否一致、为何可能值得追问。然后进入对话，一个回合只提出一个最关键问题。

## 持久化

整理后保存“素材地图摘要 + 方向 + 未决问题 + 当前阶段”检查点，不存全量原始聊天。若数据库写入失败，说明检查点没有持久化。用户后续补充内容时合并摘要并保留不确定性，不将模型的归纳回写成用户原话。
