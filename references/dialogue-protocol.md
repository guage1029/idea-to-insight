# 对话澄清

借鉴本机 `idea-clarifier` skill 的有效结构：明确阶段、提出具体挑战、把事实与假设分开、记录被舍弃路径，并在进入写作前经过关口。这里的对象是思想与读者价值，不是产品立项，也不套用 PM / 投资人角色。

## 每轮规则

- 每轮只问一个高影响问题；不要把多个问题用分号伪装成一个。
- 先复用已回答的信息，指出本轮聚焦的未知为何重要。
- 提问要求具体判断、例子、反例、因果、边界或优先级；少问“你觉得呢”一类泛问。
- 允许给出一个反例或替代判断，但标明它是 AI 提案，不是事实或用户观点。
- 用户的答案若含糊，引用含糊点，并解释它如何阻碍判断；不要替用户补出结论。
- 通常可能需要 3–5 轮，但不是上限或完成条件。根据阻塞程度决定继续与否。

## 探索顺序

按当前最关键的缺口灵活选择，而非机械问完清单：

1. **核心判断**：你最终想让读者相信、重新理解或质疑什么？
2. **读者变化**：读者读前怎么想，读后应多知道或看清什么？
3. **因果与优先级**：为何这个判断成立？哪个因素最关键？
4. **反例与替代解释**：最强的反方会怎么说？什么证据会推翻你的判断？
5. **原创增量**：AI 若只凭方向就能写出及格答案，你真正要追问的是什么？你带来了什么模型难以自行筛选的观察、经验或判断？
6. **边界**：这个结论在哪些人、情境、时间或证据条件下不成立？

## 对话结束的门槛

可进入价值判断，当且仅当已能用简洁语言表达：

- 一条候选核心判断；
- 目标读者及他们读前可能的判断；
- 读者可能形成的更准确新判断；
- 支持它的关键依据或个人贡献；
- 当前最强反例、未知或边界。

若缺少的是会改变核心判断的关键信息，继续问一个问题；不要靠写作补齐。阶段结论要列出：确定、暂定、仍未知、已舍弃的方向。
